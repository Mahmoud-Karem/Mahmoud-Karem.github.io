# Mahmoud Karem — Engineering Portfolio Website
# موقع بورتفوليو المهندس محمود كارم زامل

موقع شخصي وبورتفوليو هندسي تفاعلي يدعم اللغتين (العربية بنظام RTL والإنجليزية بنظام LTR) وتصميم Dark Theme احترافي.

## محتويات الموقع:
- **Hero:** نبذة هندسية، إحصائيات، زر تواصل، وبطاقة كود تفاعلية.
- **الخدمات:** الست باقات الأساسية (مشاريع تخرج، تدريس مقررات سعودية، برمجة متحكمات، فحص أخطاء، شبكات سيارات، ووكلاء AI).
- **المشاريع:** سابقة الأعمال المفتوحة على GitHub (مشروع التخرج V2V مع فاليو، نظام كشف الضغط، تعريفات STM32، تعريفات AVR، مشاريع AUTOSAR، وجدولة RTOS).
- **التدريس وLearn++:** التعريف بالقناة وروابطها.
- **المسيرة المهنية:** الخبرة في Valeo وSi-Vision والترتيب الأول في كلية الهندسة جامعة الأزهر.
- **التواصل:** روابط مباشرة ووسائل طلب الخدمات.

## كيفية تشغيله محلياً:
فقط افتح ملف `index.html` في أي متصفح مباشرة!

## كيفية النشر على رابطك المجاني (Mahmoud-Karem.github.io):
1. افتح التيرمينال واكتب:
   ```powershell
   gh auth login
   ```
2. ادخل إلى مجلد الموقع وشغل سكربت النشر:
   ```powershell
   cd d:\Gen_AI\Freelancing\portfolio-site
   .\deploy.ps1
   ```
   سيتم رفع الموقع ونشره تلقائياً ليصبح متاحاً للعملاء حول العالم على:
   `https://mahmoud-karem.github.io`
